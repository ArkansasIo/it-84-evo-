# Feature inventory

## Implemented in current source
- Numeric expression parser with operator precedence and constants.
- Named numeric variables.
- Trigonometric, inverse-trigonometric, logarithmic, exponential, root and rounding functions.
- Function graph sampling API with configurable x/y window and sample count.
- Matrix multiplication and determinant.
- Descriptive statistics and least-squares linear regression.
- Versioned persistent key/value memory.
- Limited BASIC-like `LET` and `PRINT` statements.
- Console shell and tests.
- Foundational keypad layout and framebuffer types.

## Not yet implemented
- Pixel-accurate TI-84 Evo LCD/skin and interactive GUI.
- Hardware-accurate emulation or compatibility with the original device.
- Complex-number data model and arithmetic.
- Complete BASIC dialect, loops, branching, editor and debugger.
- Table view, trace cursor, pan/zoom controls and equation solver.
- Statistical distributions and symbolic calculus.
- Calculator link cable / USB or proprietary file format compatibility.

The roadmap is deliberately explicit so an API or header scaffold is not mistaken for a complete feature.
