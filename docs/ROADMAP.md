# Roadmap

## Foundation
- [x] C++23 and CMake project
- [x] Numeric expression parser
- [x] Graph sampling API
- [x] Matrix multiply and determinant
- [x] Summary statistics and linear regression
- [x] Versioned memory persistence
- [x] Sandboxed BASIC-like runtime
- [x] Unit tests

## Calculator functionality
- [ ] Connect degree/radian mode to trigonometric functions
- [ ] Complex numbers
- [ ] Numerical derivative, integration and equation solving
- [ ] Matrix inverse, transpose, RREF and vectors
- [ ] Lists, distribution functions and more regressions

## Graphical UI
- [ ] LCD framebuffer and pixel renderer
- [ ] Virtual keypad keydown/keyup/repeat
- [ ] Menus, cursors and key navigation state machine
- [ ] Graph rendering with pan/zoom/trace/table
- [ ] Optional SDL2 or Qt frontend
- [ ] Keyboard navigation and high-DPI support

## Quality
- [ ] Continuous integration for MSVC, GCC, Clang
- [ ] Parser and memory-file fuzz tests
- [ ] Sanitizer builds and numerical benchmarks
